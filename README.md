TAPTAIKO CONTROL
Androidアプリ「TAPTAIKO」専用の、PC用アプリです。
スマートフォンをUSBで接続し、画面のタップをキーボード入力としてPCに送ります。
※ 本アプリ単体では動作しません。Androidアプリ「TAPTAIKO」が必要です。
ダウンロード
最新版は Releases から zip ファイルをダウンロードしてください。
使い方
ダウンロードした zip を解凍してください
解凍したフォルダの中の「TAPTAIKO CONTROL.exe」を起動してください
スマートフォンで TAPTAIKO を起動し、USBケーブルで接続してください（接続方法はアプリ内の案内をご覧ください）
ご注意： exe ファイルだけを取り出さないでください。
起動に必要なファイル一式が同じフォルダに入っています。フォルダごと移動して、そのままお使いください。
起動時に Windows の警告が出た場合
配布アプリの仕様上、起動時に「Windows によって PC が保護されました」と表示されることがあります。
その場合は「詳細情報」をクリックし、「実行」を選んでください。
動作環境
Windows PC
Androidスマートフォン（アプリ「TAPTAIKO」インストール済み）
USBケーブル
